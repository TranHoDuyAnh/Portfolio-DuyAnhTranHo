## 🌟 Core Highlights

- 🎯 **100% Real Project Verification**: Zero vanity buzzwords, zero inflated metrics. Every project, architecture, and technology listed directly corresponds to verified production codebases.
- 🌓 **Light & Dark Theme**: Sleek theme toggle with instantaneous class switching, custom CSS variable tokens, and refined contrast ratios.
- 🌐 **Full Bilingual i18n (EN / VI)**: Seamless language switching between English and Vietnamese for all headlines, project descriptions, case studies, and engineering philosophy.
- 🏗 **Interactive Case Study Modals**: Deep-dive technical modal for each project with architectural diagrams, problem/solution breakdowns, core features, and engineering challenges.
- ⚡ **Optimized Performance & SEO**: Strict type checking (`tsc --noEmit`), dynamic `sitemap.xml`, `robots.txt`, OpenGraph metadata, and sub-second load times.

## 🛠 Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Language**: [TypeScript 5](https://www.typescriptlang.org/) (Strict Mode)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Theming**: [next-themes](https://github.com/pacocoursey/next-themes)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Components**: Component-driven architecture with clean separation of data (`data/projects.ts`, `data/skills.ts`, `data/profile.ts`).

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

### 3. Build for Production
```bash
npm run build
npm start
```

### 4. Type Safety Verification
```bash
npm run typecheck
```
